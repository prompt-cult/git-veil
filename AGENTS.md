# AGENTS.md

## Instructions for AI Agents

When committing changes to this repository:

- **DO NOT** add any advertising or attribution lines to commit messages
- **DO NOT** include "Generated by Mistral Vibe" or "Co-Authored-By: Mistral Vibe" in any commits
- Use clear, descriptive commit messages that explain what changed and why
- Follow conventional commit style: `<type>: <description>`
- Types include: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`, `wip`
