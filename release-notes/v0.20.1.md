## Windows

The Windows portable ZIP now contains `git-veil.exe`, so the command has the
expected name when WinGet adds the package directory to PATH. It is built from
the same executable as the standalone Windows EXE and MSI.

The release provides the portable ZIP, standalone EXE and MSI, each with a
SHA-256 checksum. The WinGet package is submitted separately and is available
through WinGet only after the community repository accepts it.

## Release process

CI resolves the release tag to a commit on main and builds each platform from
that commit. It verifies the staged asset checksums and publishes the release
after the builds, Windows installer test and fuzz smoke tests pass. Published
release assets are immutable.
